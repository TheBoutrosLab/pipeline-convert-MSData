Pipeline Steps

The input MS data is converted using either msconvert from ProteoWizard, followed by a call to the FileConverter command from OpenMS (which can be turned off by setting run_index to false). This is to remove errors from files (e.g. the index), to update file formats to new versions, or to check whether information is lost upon reading or writing (see here). For mzML, the PeakPickerHiRes command from OpenMS can used to convert it into centroid mzML as an alternative to the vendor specific peak picking. However only one pick picking algorithm should run.

This pipeline supports all file formats that OpenMS and ProteoWizard supports. For OpenMS, find the list of formats here, and for ProteoWizard here. The PeakPickerHiRes from OpenMS only supports output format as mzML.
